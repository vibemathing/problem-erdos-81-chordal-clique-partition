# C05 source-faithfulness: transformation names and remaining source gaps

Verdict: candidate_only. Retrieved 2026-09-06. This note does not certify any mathematical proof.

## K1. Kelmans definition; parameter scope is different

Péter Csikvári, "Applications of the Kelmans Transformation: Extremality of the Threshold Graphs", author-hosted corrected manuscript, version identified by filename `application_Kelmans_corrected.pdf`.
https://csikvarip.web.elte.hu/application_Kelmans_corrected.pdf

Definition 2.1 on printed page 2 (PDF index 1) defines the edge migration by moving the co-beneficiary's private neighbors to the beneficiary. The page was visually inspected. Its definition preserves edge count. The manuscript studies specified polynomial, matching and spectral parameters; no cp monotonicity is supplied by this reuse. C05.1 uses the definition with beneficiary v and co-beneficiary u, then proves its own cp values. No publication year, PDF digest, general chordality-preservation result, or novelty claim is inferred from this source.

## K2. Structural theorem already scoped in C01

Bochuan Lyu and Illya V. Hicks, "Finding Biclique Partitions of Co-Chordal Graphs", arXiv:2203.02837v2, Section 2.
https://arxiv.org/html/2203.02837v2

Only the PEO/chordal characterization is used for C05.2. Its main biclique parameter is not cp. The folding in C05.2 is a proposed candidate operation, not a theorem attributed to this paper.
